4. Security & Architecture Highlights
Token Invalidation
Implements an atomic tokenVersion on the user record. Logging out or resetting passwords increments the version, immediately revoking all stale JWTs across all devices.
Suspension Shield
Suspending an account (ACCOUNT_SUSPENDED) revokes active JWT sessions and blocks subsequent logins with 403 Forbidden, preventing unauthorized platform activity.
Strict Password Security
Passwords hashed with 10 salt rounds of bcryptjs. Enforces length >= 8, uppercase, lowercase, numerical digit, and special symbol checks on registration and password changes.
